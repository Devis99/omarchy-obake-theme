# Wallpaper sources

Each wallpaper is a figure cut from the scan below and recolored with the Obake palette. All source works are in the public domain or released under CC0.

| Wallpaper | Work | Source |
|---|---|---|
| `01-lantern-ghost.png` | Katsushika Hokusai, *Oiwa*, from *Hyaku monogatari* (One Hundred Ghost Tales), c. 1831 | [Rijksmuseum via Wikimedia Commons](https://commons.wikimedia.org/wiki/File:O-Iwa_het_lantaarn_spook_O-iwa-san_%28titel_op_object%29_Honderd_verhalen_%28serietitel%29_Hyaku_monogatari_%28serietitel_op_object%29%2C_AK-MAK-930.jpg) — CC0 |
| `02-skeleton-spectre.png` | Utagawa Kuniyoshi, *Takiyasha the Witch and the Skeleton Spectre*, c. 1844 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Takiyasha_the_Witch_and_the_Skeleton_Spectre%2C_by_Utagawa_Kuniyoshi.jpg) — public domain |
| `03-lantern-cat.png` | Kobayashi Kiyochika, *Neko to chōchin* (Cat and Lantern), 1877 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Kobayashi_Kiyochika_%281877%29_Neko_to_chouchin.jpg) — public domain |
| `04-moths.png` | Kubo Shunman, surimono of moths | [The Metropolitan Museum of Art via Wikimedia Commons](https://commons.wikimedia.org/wiki/File:MET_DP139026.jpg) — CC0 |
| `05-crow.png` | Kawanabe Kyōsai, *Crow Flying in the Snow* | [The Metropolitan Museum of Art via Wikimedia Commons](https://commons.wikimedia.org/wiki/File:%E9%9B%AA%E4%B8%AD%E9%B4%89%E5%9B%B3-Crow_Flying_in_the_Snow_MET_DP211822.jpg) — CC0 |

The Vencord theme is [Midnight](https://github.com/refact0r/midnight-discord) by refact0r, recolored. `gtk.css` follows the standard GTK layout used by HANCORE's Omarchy themes (MIT), recolored.
